This is a FORK of the notmuch project. It adds additional sorting
options, on the command-line and in the Emacs interface:

```
notmuch search --sort=ORDER SEARCH-TERMS
```

Where `ORDER` is one of:

- newest-first
- oldest-first
- from-ascending
- from-descending
- subject-ascending
- subject-descending

For more information about the upstream project, see
[notmuchmail.org](https://notmuchmail.org).
